# preview.6：创建界面修订与鼠标垫识别

## 修订

- 角色页创建按钮改为醒目主按钮；设置、创建向导、鼠标修复窗统一使用内嵌 Dagaka.ico，辅助窗不创建任务栏入口，创建和修复窗继续由父窗口拥有。
- 标题区留出实际字体高度，移除侧栏底部冗余说明。文件路径改为文件卡片，名称使用圆角输入。提示词改为自适应高度文字卡片与复制按钮，取消提示词输入框及内部滚动；窗口较小时只滚动整个页面。
- 参考图复制/保存并排；生图工具称谓与推荐按用户要求修改。按键提示词只将“让这只熊”改为“让上图角色”。
- 方向展开后空白的复现原因：滚动容器残留旧偏移，页面 Y 坐标成为正值（实测 658），整页在可视范围外。统一页高与宽度约束，布局防重入，并将页原点对齐当前滚动位置。修复卡片背景覆盖兄弟控件及教程选择栏自动高度遮挡内容。
- 鼠标工具改等宽网格，取消更多菜单与圈手入口；公开点选、补涂、擦除、撤销、连接处、中心、鼠标垫点选与备用圈垫。底部取消、复制、确认固定展示。
- 每张原图独立识别连续灰色垫面，以凸包补齐手和鼠标遮挡处。点选鼠标垫可重新识别；透明区域/白色鼠标无效点击不会替换原垫面。复制选区时重新识别目标姿势，避免复制旧垫面位置。

## 限制

鼠标垫识别针对纯灰、近似凸形垫面，不承诺任意纹理或凹形物体均能自动分离。若自动预判不准可点灰色区域，必要时使用备用圈垫。创建向导仍是新角色入口，不包含旧角色就地编辑。
