# 创建角色向导与鼠标选区 · preview.5

## 交付范围

四步向导及鼠标调整页采用现有设置页的奶油色、棕金渐变、圆角卡片与胶囊按钮。制作提示词保持用户原文，图文教程默认从第一步开始；保留复制提示词、复制和保存参考图、四张透明图片上传、最终预览和取消流程。

鼠标调整默认提供点选、补涂、擦除、撤销。连接点、鼠标中心、鼠标垫圈选与灰色细节开关收进“更多调整”。按住画笔显示真实图像和选区的 3× 放大镜，松开或丢失鼠标捕获后关闭。每个姿势仍须分别确认。

点选使用连续颜色和肩膀到鼠标的有限区域；通常先点鼠标，再点手臂。补边仅补入原有明亮/彩色选区附近的暗色轮廓，保护鼠标垫外框，新增像素不会成为下次扩张的种子。此功能不能语义识别任意形状，漏选或误选仍可用画笔修正。
