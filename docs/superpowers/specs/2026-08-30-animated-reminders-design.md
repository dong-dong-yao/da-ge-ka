# 动画提醒设计规格

## 范围

- 第一层打卡提醒不再显示静态表情包，改为透明背景逐帧角色动画。
- 动画随机出现在主屏幕工作区的上、下、左、右边缘；同一套原始动画通过镜像或旋转复用。
- 第一段视频保持原始约 7.1 秒节奏，不压缩到 5 秒；忽略音轨。
- 打卡气泡显示“你打卡了吗？”和“已打卡，闭嘴”按钮。动画结束仍未点击时自动关闭。
- 新增可关闭的久坐提醒，默认关闭；默认时间为 09:00–18:00；间隔仅允许 60、90、120、180 分钟。
- 久坐提醒使用固定时间锚点，不因弹窗延迟而平移下一次提醒；文案为“坐太久啦，该站起来活动一下了”，没有按钮，不能抢焦点，随动画自动消失。
- 打卡提醒优先于久坐提醒。冲突时最多保留一个久坐待提醒；打卡流程结束后再展示，未来固定节点不变。
- 第二道闸门仍居中显示固定文案“真的吗，那你为什么不走”和“真的 / 假的”按钮。
- 第二段 640×640、24 FPS、约 4.09 秒绿幕视频抠成透明逐帧动画；播放完直接从第一帧重新开始，不倒放，不自动关闭。
- 晚间确认和关机/重启拦截共用同一套第二道闸门。
- 暂不处理多显示器和全屏应用。

## 动画资源与播放

- 构建期把两段 MP4 解码为 12 FPS PNG。降低帧率只减少帧数，不改变总播放时长。
- 对绿幕像素做软阈值抠图，完全绿色区域 alpha 为 0，边缘使用渐变 alpha，避免明显绿边。
- PNG 作为嵌入式资源随单文件 EXE 发布，不在运行时依赖 MP4、FFmpeg 或外部素材目录。
- 第一段播放一次；第二段无限顺序循环。
- 动画窗口使用透明色背景、无边框、置顶、不出现在任务栏。第一层窗口使用 NoActivate，点击仅发生在独立气泡按钮上。

## 设置与兼容

- 新增 `BreakReminderEnabled`、`BreakStart`、`BreakEnd`、`BreakIntervalMinutes` 四项设置。
- 旧配置 JSON 缺少新字段时，由属性默认值自动迁移，不清空既有六项设置。
- 久坐开始时间必须早于结束时间，间隔必须属于 60、90、120、180。
- 不保存打卡完成状态、久坐展示历史、日期或动画播放位置。

## 验收

- 自动测试覆盖久坐窗口边界、固定节点、合法间隔、旧配置迁移和提醒优先级状态机。
- Release 测试全部通过，构建 0 警告 0 错误。
- 发布为 `win-x64`、self-contained、single-file、禁止 trimming。
- 不自动执行真实关机或重启测试；视觉透明度、焦点、托盘和结束会话继续列为 Windows 人工验收项。
