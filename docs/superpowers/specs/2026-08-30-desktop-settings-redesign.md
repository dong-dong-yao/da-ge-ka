# “打个卡”桌面设置界面设计

## 目标

把当前纵向系统控件式设置窗口改成适合 Windows 桌面端的暖色双栏界面，同时加入真正可用、可扩展的角色选择功能。

## 布局

- 窗口采用约 860×700 的桌面比例，不照搬手机底部导航。
- 顶部为品牌标题区；左栏放上午、晚上、久坐和开机启动设置；右栏放角色预览与选择。
- 底部仅保留真实可用的“测试提醒”和“保存全部设置”。

## 视觉

- 奶油白背景、暖黄色到焦糖棕的品牌色、圆角白色卡片、柔和阴影。
- 输入控件保持键盘可操作和清晰对比度。
- 按钮具备悬停、按下反馈；窗口内容淡入；角色确认有状态反馈。

## 角色选择

- 当前角色为 `white-bear`，界面显示真实 Edge 动画预览。
- 左右箭头是实际角色浏览控件；只有一个角色时自动禁用。
- “使用这个角色”确认当前预览角色；“保存全部设置”持久化角色与其他设置。
- 角色目录以稳定 ID、显示名、动画序列名和动画时长描述，后续添加角色无需重写设置窗口。

## 兼容与边界

- 旧配置缺少角色字段时自动使用 `white-bear`。
- 不改变提醒文案、调度、第二道闸门、关机拦截及动画原始速度。
- 发布仍为 Windows x64、self-contained、single-file、禁止 trimming。
